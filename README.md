# TEMBUX-MGC

Team TembuX · Medical Grand Challenge 2026 · Project 1464
**AeroGlide** — an integrated unweighting and anchoring system for lateral patient transfer.

## Contents
- **`aeroglide-film/`** — Remotion pipeline for the competition film (3:45 · 1920×1080 · 30fps). See its own README for install/render/retiming instructions.
- **`remotion-video/`** — the standalone AeroGlide product-reveal video (60fps cinematic cut) used as the film's v2 source footage.
- **`transfer-bridge-landing/`** — the interactive 3D/scroll product landing page (React Three Fiber), deployed at https://smart-transfer-bridge-v2.vercel.app.

Each folder is independently installable (`npm install`) and has its own README with details.
